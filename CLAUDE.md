# Project Instructions

Canonical agent instructions; other agents use the `AGENTS.md` pointer.

## This repository
Mobile-first photo OCR — capture/upload N photos of a document, screen, or page; a vision-capable model on the local LLM hub returns one clean, deduplicated, copy-ready text. Sister project to `voice-transcriber` (same conventions, archive shape, auth model), for pixels instead of audio. See `README.md` for setup, layout, and usage.

**Project specifics:**

- **Stack:** FastAPI + vanilla JS — **not** Streamlit; do not introduce Streamlit.
- **Config & secrets:** there is no `.env`. Project config lives in `config/config.json` (committed) and runtime UI prefs + secrets (`auth_token`, `auth_password`) in `config/webapp_config.json` (gitignored).
- **Verification — webapp boot check:** `& .\.venv\Scripts\python.exe -m uvicorn app.webapp.server:app --host 127.0.0.1 --port 8444` then `curl http://127.0.0.1:8444/healthz`.
- **Pre-ship gate:** any change under `app/webapp/` (or the webapp-facing `src/` modules) must pass `powershell.exe -File scripts/verify-before-ship.ps1` before it is declared done. Use Windows PowerShell 5.1 (`powershell.exe`, or absolute `C:/Windows/System32/WindowsPowerShell/v1.0/powershell.exe`), not `pwsh` (a 0-byte WindowsApps stub that fails non-interactively).
- **e2e runtime contract:** the e2e leg of the pre-ship gate collects 32 nodes (Chromium + WebKit/iPhone, auto-booted): 25 executed, 7 skipped by design (the server-side cache-busting and cert checks run once on Chromium, the iPhone-projection check on WebKit only). Measured 2026-10-07: 23 s session time, of which the rendered-geometry node (`test_geometry.py`, 8 viewport x theme legs per engine) is ~6 s (whole gate, byte-compile + static ratchet + 231 unit tests + e2e, ~33 s). Investigate a gate that takes over ~30 s; a test that sleeps or polls in real time belongs on the page clock (`page.clock`), not a timer. The gate writes JUnit to `webapp/e2e-junit.xml` (gitignored), declared as `[e2e] junit_xml` in `.fleet.toml` for `/e2e-audit`. The gate routes the e2e leg on the branch diff vs `origin/main` through the vendored `scripts/classify_e2e.py` (rules in `.fleet.toml` `[e2e]`): `skip` (docs / markdown / desktop assets only) skips the leg and prints the tier and reason, `static` runs the declared smoke slice (`tests/e2e/test_smoke.py`, Chromium), `full` runs the whole suite; a classifier error or a missing/unknown tier falls back to `full` with its own message, and CI always runs `full`. Counts and timings describe a `full` run; a skipped leg writes no JUnit, so `webapp/e2e-junit.xml` is the last run that did.
- **Static ratchet:** the gate's second stage runs `python -m scripts.static_ratchet_gate`, a wrapper over the vendored `scripts/static_ratchet.py` (rules in `.fleet.toml` `[static_ratchet]`). A duplicate block (jscpd via `npx`) or an unused import/variable (ruff `F401,F841`) that is not in `.static-ratchet-baseline.json` fails the gate by name. Exit 3 (a detector could not run: no Node, no network on the first `npx`, ruff missing) fails as NOT CONFIRMED, never a pass. Needs Node and `ruff` in the `.venv` (`requirements-dev.txt`). It reads the whole tree, so it is not path-routed. Shrink the baseline with `--update-baseline` in the PR that removes debt; adding entries needs `--allow-additions`.
- **Docs ratchet:** the gate's third stage runs `python -m scripts.docs_ratchet_gate`, a wrapper over the vendored `scripts/docs_ratchet.py` (rules in `.fleet.toml` `[docs_ratchet]`). `README.md` growing past 40 KiB or past its baselined size, or `README.md` / `docs/**/*.md` gaining an issue reference, dated heading or changelog heading beyond `.docs-ratchet-baseline.json`, fails the gate by file and line. Exit 3 (a doc could not be read) fails as NOT CONFIRMED, never a pass. It counts the whole tree, so it is not path-routed and runs on a docs-only diff too. State the present-tense why in new docs; shrink the baseline with `--update-baseline` in the PR that removes debt.
- **Structure ratchet:** the gate's fourth stage runs the vendored `scripts/structure_ratchet.py` directly (rules in `.fleet.toml` `[structure_ratchet]`, shape `webapp-tray`, `extra_roots = ["webapp"]`). A file over 1,000 lines, a function over 100 lines, a directory over 40 modules or a `src`→`app` import beyond `.structure-ratchet-baseline.json` fails the gate by name; a tracked root folder outside the shape fails too and is never baselined. Exit 3 (unmeasurable file, unknown shape) fails as NOT CONFIRMED, never a pass. Whole-tree, so not path-routed. New code goes where `docs/layout.md` says; split rather than grow a baselined offender, and shrink the baseline with `--update-baseline` in the PR that does.
- **Design inventory (fleet-config#1383):** every surface a test opens carries `surface(page, "<tab>.<surface>")` (vendored `tests/e2e/_surface.py`, `[vendored] surface_capture`; `[design.review] theme_storage_key = "photo-ocr.theme"` lets it flip the app's explicit theme). It is inert on every normal run. `/design-review measure photo-ocr --e2e` arms it on the throwaway webapp `scripts/design_review_synthetic.py` declares (`[design.review.synthetic]`, never the live `:8444`) and keeps only the tests whose **own body** calls `surface(` (a call inside a helper does not select its test). A new sheet or state a test opens takes one `surface(...)` call beside its last assertion; `measure --e2e` must keep reporting zero not-walked overlays. Tag a transient toast or a popover that closes on scroll only when the test does nothing with it afterwards.
- **Restart and verify before hand-off:** no hot-reload — edits do nothing until the `:8444` process restarts. Canonical restart: **`tray.bat --restart`** (orphan-proof: kills the tray subtree, reclaims `:8444` by PID scoped to this repo's `.venv`, starts fresh). Don't hand-roll the kill (misses an orphaned port holder). By-hand fallback only: kill the process listening on `:8444` (`Get-NetTCPConnection -LocalPort 8444`) — never a blanket `pythonw`/`python` kill, sister apps must survive — then relaunch via `tray.bat`. **Confirm the new build is live** via `curl -k https://127.0.0.1:8444/healthz` (200) before handing off. (The tray-launched webapp serves **HTTPS** with a `.ts.net` cert from `tailscale cert`, hence `-k`/`https` — plain `http://` fails at TLS and reads as a false "not live". The manual boot-check above is plain `http` on purpose.)

## CI expectations
- Workflow `.github/workflows/ci.yml`, job `gate`, on every PR and on pushes to `main`. **Advisory, not required** (no branch protection) — the local gate is the contract. The job runs `scripts/verify-before-ship.ps1` on a clean `windows-2025` runner (fresh `.venv`, `playwright install chromium webkit`, `config/*.sample.*` seeded), one definition of green.
- Typical green: **~2.5 min**. Investigate at **>5 min**; treat as wedged at **>10 min**.
- Flaky leg: the WebKit/iPhone e2e projection can wedge on the hosted runner (capped by `timeout-minutes: 10`); a wedge is a flake, not the diff.
- CI's only signal beyond the local gate is the clean machine (uncommitted file, dev-box-only dependency, state-dependent test) and the hosted-runner timing of the e2e suite. Its e2e surface = `app/webapp/`, `src/`, `tests/e2e/`, `scripts/verify-before-ship.ps1`, `scripts/classify_e2e.py`, `requirements*.txt`, `.github/workflows/ci.yml`. A diff touching none of these (docs, markdown, desktop `assets/`) gains nothing from CI.
