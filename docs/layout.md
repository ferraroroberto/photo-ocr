# Layout

Where new code goes, and why each top-level folder exists. The structure ratchet (`scripts/structure_ratchet.py`, rules in `.fleet.toml`) checks this layout on every gate run: the shape is `webapp-tray`, so `app`, `src`, `tests` and `docs` are required, and `scripts`, `data`, `brand`, `assets` and `config` are allowed by the preset. The README's "Repo layout" section is the file-by-file tree; this page is the placement rule.

## Top-level folders

| Folder | Holds | Rule |
|---|---|---|
| `app/` | Everything that runs as a process: CLI, tray, FastAPI webapp | May import `src/`. |
| `src/` | The logic layer: OCR client, archive, extract jobs, config | Never imports `app/`; the ratchet's layer check fails it. |
| `tests/` | Unit tests at the top, Playwright e2e under `tests/e2e/` | Same size limits as code. |
| `docs/` | Durable reference, present tense | No plans, no dated notes; the docs ratchet counts history markers. |
| `scripts/` | Gate stages, ratchets, one-shot operator tools | Vendored scripts are never edited here. |
| `config/` | Committed app config and the prompt library | Secrets and runtime prefs stay in the gitignored `webapp_config.json`. |
| `assets/` | Tray and Stream Deck icons generated by `scripts/gen_icons.py` | Desktop-only; never served to the browser. |
| `webapp/` | Named-tunnel config template (`cloudflared.sample.yml`) | A declared exception, see below. |

## Subpackages

| Path | Holds |
|---|---|
| `app/cli/` | argparse dispatcher; one module per command under `app/cli/commands/` |
| `app/tray/` | system-tray launcher, single-instance lock, webapp watchdog |
| `app/webapp/` | FastAPI app factory, auth middleware, uvicorn manager |
| `app/webapp/routers/` | one `APIRouter` per concern (misc, config, auth, sessions, search) |
| `app/webapp/static/` | the PWA: HTML, ES-module JS, CSS, icons |
| `app/webapp/static/_vendored/` | fleet components copied verbatim from project-scaffolding; never edited, excluded from the ratchet |
| `tests/e2e/` | browser tests on Chromium and WebKit/iPhone against a disposable webapp |

New backend logic goes in `src/` as a module, not in a router; a router stays a thin HTTP adapter over it. A module that would push a directory past 40 files goes in a domain subpackage.

## Declared exceptions

- **`webapp/` in `extra_roots`.** The `webapp-tray` preset does not list it. The folder holds the tunnel config template, and the same path is where the gitignored live `cloudflared.yml`, the TLS certificates, the tunnel URL file, the watchdog log and the e2e JUnit output sit at runtime, so `webapp/` cannot move without changing the paths the tray and the webapp manager read. It is declared as data in `.fleet.toml`, not baselined.

## Baselined offenders

`.structure-ratchet-baseline.json` is empty: no file is over 1,000 lines, no function over 100 lines and no directory over 40 modules. A new offender fails the gate; split it instead of baselining it.
